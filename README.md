#  Real-Time Digital Clock

A simple, responsive, and lightweight **digital clock** built with **HTML, CSS, and JavaScript**. The project uses JavaScript's `Date` API and DOM manipulation to display the current time and date in real time.

##  Features

*  **Real-Time Updates** — Clock updates automatically every second.
*  **Current Date & Time** — Displays the current date along with the time.
*  **Responsive Design** — Works smoothly across desktop, tablet, and mobile screens.
*  **Clean UI** — Simple and minimal interface focused on readability.
*  **Lightweight** — No external libraries or frameworks required.
*  **Browser-Based** — Runs directly in any modern web browser.
