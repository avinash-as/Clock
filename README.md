A simple and responsive real-time digital clock built using HTML, CSS, and JavaScript.

The project demonstrates how JavaScript can work with the browser's Date API and DOM to display and continuously update the current time in a clean and user-friendly interface.

✨ Features
🕐 Real-time clock updates
📅 Displays current date
🔄 Automatically updates every second
📱 Responsive design
🎨 Clean and minimal user interface
⚡ Lightweight and fast
🌐 Runs directly in the browser


🎯 Learning Outcomes

This project helped practice:

JavaScript Date and Time APIs
DOM manipulation
setInterval() / timed updates
HTML structure
CSS styling
Responsive web design
Building a small frontend project from scratch
